# Chapter 4 C# Loops

## Topics Covered

This week, I learned about loop structures and repetition in C# Windows Forms.

### 1. While Loop
- Using the `while` loop
- Repeating code while a condition is true
- Understanding loop conditions

### 2. Increment and Decrement Operators
- Increment operator (`++`)
- Decrement operator (`--`)
- Increasing and decreasing variable values

### 3. For Loop
- Using the `for` loop
- Understanding initialization, condition, and update
- Repeating code a specific number of times

### 4. Counting Backward
- Using a `for` loop to count backward
- Decreasing values using (`--`)
- Controlling loop execution

### 5. Do-While Loop
- Using the `do-while` loop
- Checking the condition after executing the code
- Understanding that the loop executes at least once

### 6. Random Numbers
- Using the `Random` class
- Generating random numbers
- Using the `Next()` method

## Learning Objectives

- Understand loop structures in C#.
- Use `while`, `for`, and `do-while` loops.
- Apply increment and decrement operators.
- Control repetition using loop conditions.
- Count forward and backward using loops.
- Generate random numbers using the `Random` class.

In Week 4, I learned how to repeat code using different loop structures in C#. I also practiced using increment and decrement operators, counting backward, and generating random numbers.
